Estructura del proyecto

Las carpetas separan el código Java, las vistas HTML, los estilos, JavaScript y las pruebas. 

origen/
├── src/
│   ├── main/
│   │   ├── java/          Controladores y aplicación principal
│   │   └── resources/
│   │       ├── templates/ Vistas HTML con Thymeleaf
│   │       ├── static/    Archivos CSS y JavaScript
│   │       └── application.properties
│   └── test/              Pruebas del proyecto
├── Dockerfile             Creación del contenedor
├── pom.xml                Dependencias de Maven
└── README.md              Información del proyecto

Controladores

Los controladores reciben las solicitudes que hace el usuario desde el navegador y deciden qué página se debe mostrar.

InicioController: maneja la ruta /. Cuando el usuario entra a la página principal, este controlador devuelve la vista pagina.html.

ContactoController: maneja la ruta /contacto. Cuando el usuario selecciona Contáctanos, este controlador devuelve la vista contacto.html.

Vistas

Las vistas están guardadas en la carpeta src/main/resources/templates. Son archivos HTML que Thymeleaf procesa antes de enviarlos al navegador.

  • pagina.html: es la página de inicio y contiene el menú principal de navegación.
  • arquitectura.html: documenta la organización, las dependencias y el funcionamiento del proyecto.
  • contacto.html: contiene el formulario de contacto con los campos solicitados en el taller.

Archivos estáticos

La carpeta src/main/resources/static contiene los archivos que el navegador puede utilizar directamente. Dentro de ella se separan los estilos CSS y el código JavaScript.

  • css/contacto.css: define la apariencia del formulario de contacto.
  • js/contacto-validacion.js: comprueba los campos del formulario y muestra los mensajes de error.

Flujo MVC

El proyecto sigue el patrón Modelo, Vista y Controlador. Primero, el navegador solicita una ruta. Después, Spring busca el controlador encargado de esa ruta. El controlador prepara los datos necesarios y devuelve el nombre de una vista. Finalmente, Thymeleaf procesa el HTML y Spring lo envía al navegador.

  1. El usuario entra a una dirección desde el navegador.
  2. El controlador recibe la solicitud HTTP.
  3. El controlador prepara los datos del modelo.
  4. Thymeleaf procesa la vista HTML seleccionada.
  5. El navegador muestra el HTML resultante.

Spring Boot

Spring Boot es la herramienta que permite iniciar y ejecutar la aplicación web. Incluye un servidor dentro del proyecto, por lo que no es necesario instalar un servidor web por separado.

Cuando Spring Boot está funcionando, recibe las solicitudes del navegador, busca el controlador correspondiente y le entrega la solicitud. Después, el controlador selecciona una vista y Spring Boot utiliza Thymeleaf para convertir esa plantilla en el HTML final.

Spring Boot también publica los archivos guardados en la carpeta static. Por eso puede cargar los estilos CSS y el JavaScript mediante rutas como /css/contacto.css y /js/contacto-validacion.js.

Si un archivo HTML se abre sin ejecutar Spring Boot, el navegador puede mostrar su contenido básico, pero no procesa las instrucciones de Thymeleaf que comienzan con th:. Para comprobar completamente la aplicación se debe iniciar Spring Boot y entrar por una ruta definida en los controladores.

Configuración

El archivo application.properties guarda la configuración de Spring Boot. Por ahora, indica que el nombre de la aplicación es wikitaller. Más adelante puede incluir otras configuraciones, como el puerto o la conexión a una base de datos.

Maven y pom.xml

Maven organiza la construcción del proyecto. El archivo pom.xml indica la versión de Java, las dependencias y los complementos necesarios. Cuando se ejecuta Maven, descarga las librerías y crea el archivo ejecutable de la aplicación.

Dockerfile

El Dockerfile contiene los pasos para construir y ejecutar DevWiki dentro de un contenedor. Primero usa Java 17 para compilar el proyecto con Maven. Después copia el archivo generado a una imagen más pequeña con Java 17, habilita el puerto 8080 y ejecuta la aplicación.

Pruebas

La carpeta src/test contiene las pruebas automáticas. Estas pruebas permiten revisar que Spring Boot pueda cargar la aplicación correctamente y ayudan a detectar errores antes del despliegue.

Dependencias

  • Thymeleaf: crea las vistas HTML dinámicas.
  • Spring Web MVC: conecta las rutas, los controladores y las vistas.
  • Lombok: reduce código repetitivo en las clases Java.
  • Dependencias de prueba: permiten comprobar el funcionamiento del proyecto.
