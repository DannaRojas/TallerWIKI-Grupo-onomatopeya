DevWiki - Grupo Onomatopeya

Esta wiki documenta el proyecto semestral de Desarrollo Web y el avance realizado por el grupo Onomatopeya.

¿Qué es el proyecto?

El proyecto consiste en crear un Sistema de Gestión de Procesos multiempresa. Cada organización tendrá su propio espacio para registrar usuarios y administrar sus procesos empresariales.

La información pertenece a cada empresa, por lo que los usuarios solo podrán consultar y modificar los datos autorizados para su organización.

¿Qué podrá hacer el sistema?

  • Registrar empresas, usuarios y roles de acceso.
  • Crear, editar, consultar y desactivar procesos.
  • Guardar el nombre, descripción, categoría y estado de cada proceso.
  • Modelar procesos con actividades, decisiones, roles y participantes.
  • Consultar el historial de cambios de los procesos.

Grupo Onomatopeya

Somos un grupo de estudiantes de Desarrollo Web. Durante el semestre construiremos el proyecto de forma incremental y registraremos en esta wiki las decisiones, la arquitectura y los avances del equipo.

Organizamos las tareas en un tablero Kanban y usamos reuniones daily para compartir avances, planear el trabajo y comunicar bloqueos.
